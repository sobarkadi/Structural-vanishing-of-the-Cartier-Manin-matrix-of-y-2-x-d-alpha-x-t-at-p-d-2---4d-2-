# Structural-vanishing-of-the-Cartier-Manin-matrix-of-y-2-x-d-alpha-x-t-at-p-d-2---4d-2-
In characteristic p>0, a smooth projective curve is ordinary if its p-rank equals its genus g. For hyperelliptic curves y²=f(x) (p odd), this is determined by the invertibility of the Hasse-Witt matrix C, whose entries derived from \(f^{(p-1)/2}\) depend on multinomial coefficient vanishing.
